# Historical design records

- [Project design](PROJECT.md)

- `assets/`: diagrams from earlier design drafts, including the superseded
  [memory API sketch](assets/hierarchical-memory.svg). These are historical

These records preserve earlier proposals, names and implementation milestones.
They are not the current support contract and are excluded from the user-facing
documentation site. Refer to the [API](../api.md), [support matrix](../roadmap.md)
and regression tests for current behavior. Archived benchmark inputs and source
snapshots also retain their original names and hashes.
