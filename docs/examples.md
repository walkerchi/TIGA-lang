# Examples

Every example is an ordinary user-defined program. None calls a GraphForge
algorithm operator.

| Example | Relation/reducer feature | Expected path today |
|---|---|---|
| `tensor_autograd.py` | Tensor add/mul/sum and functional VJP | canonical `gf_tensor` + native VJP pass + CPU execution |
| `complex_autograd.py` | complex views and conjugate-Wirtinger VJP | native CPU storage + correctness evaluator |
| `message_passing_autograd.py` | static CSR UDF + sum VJP + checkpoint policy | native `gf_tensor` → LLVM CPU JIT / CUDA TTIR |
| `gcn.py` | static CSR, vector sum and broadcast VJP | native relation Tensor IR |
| `diffusion.py` | source/destination message + node update VJP | native relation Tensor IR |
| `custom_reducer.py` | user tuple-state mean algebra | structural additive lowering + native automatic VJP |
| `tensor_matmul.py` | rank-2 contraction and both operand gradients | CPU LLVM / FP16 GPU `tt.dot` |
| `distributed_halo.py` | paged `.gfg`, two-process rank-local forward and VJP | bounded shard read + automatic owner→ghost/reverse exchange |
| `torch_interop.py` | optional compatibility/zero-copy boundary | Torch adapter |

Run them from a source checkout:

```bash
export PYTHONPATH="$PWD/python"
python examples/tensor_autograd.py
python examples/complex_autograd.py
python examples/message_passing_autograd.py
python examples/gcn.py
python examples/diffusion.py
python examples/custom_reducer.py
python examples/torch_interop.py  # optional
```

## Minimal Tensor and VJP

This example does not import Torch. It uses the native GraphForge buffer
runtime, captures a deferred expression and constructs its reverse-mode VJP.
The example prints the verified canonical forward IR and the Tensor IR emitted
by `gf-tensor-vjp`. Execution still uses the Python oracle for this tiny shape;
larger supported CPU DAGs use the bootstrap fused-loop provider.

## Differentiable MessagePassing UDF

The user defines only `edge` and `node`. Relation gather/segment primitives and
their VJP are generated by the compiler; no backward function is written.
The example also shows an explicit `save` checkpoint; on CUDA `auto` chooses
between saved relation gathers and recomputation.

--8<-- "examples/message_passing_autograd.py"
